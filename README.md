FOKHARA DIGITAL MENU
=====================

Static Vercel-ready website.

Structure:
- index.html       Home page
- menu/index.html  Digital menu page
- logo.png         Official logo for home
- menu/assets/     Menu assets
- menu.jpg         Original menu reference

The home page button "تصفح المنيو" opens /menu/.

Mobile-first responsive behavior:
- one-column menu cards on small screens
- touch-friendly category navigation
- no horizontal page overflow
- responsive typography and images
- safe-area support for mobile devices

Deploy:
Upload this folder to Vercel, or push it to GitHub and connect the repository to Vercel.
